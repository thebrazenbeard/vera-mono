# Mini-Vera synthetic local inference seam (source-only candidate)

The merged zero-weight composer (`tools/mini_vera/compose.py`) emits a bounded
**synthetic-only** request. `tools/mini_vera/loopback.py` can validate that
request and, **only with `--execute`**, send it to an already-running local
OpenAI-compatible `/v1/chat/completions` server. No model is installed or
launched. No downloads, key retrieval, memory reads/writes or external actions
are performed. An operator must explicitly select the local model alias and
endpoint outside this adapter.

```powershell
# The input is a JSON file previously generated by compose.py with its required
# source SHA-256 and synthetic-state checks. Adapt paths to your isolated workdir.
python tools/mini_vera/loopback.py --request candidate.json --endpoint http://127.0.0.1:8080/v1
# Prints VALIDATED_NOT_EXECUTED; sends no request and writes no output.

python tools/mini_vera/loopback.py --request candidate.json --endpoint http://127.0.0.1:8080/v1 `
  --execute --timeout-seconds 30 --output result.json
# Sends exactly one bounded request. Output must not already exist.
```

**Boundaries:** Only numeric `127.0.0.1`/`[::1]` HTTP endpoints with explicit
ports and exact `/v1` paths are accepted; there is no DNS, URL redirection,
proxy handling, authentication header, or client-provided tools. A single
wall-clock deadline spans connection, response headers and body. Response size,
request size, and output length are bounded. Redirects, tool calls, malformed
JSON, unexpected model aliases and control characters in model text are
rejected. `finish_reason=length` yields an explicitly **truncated** result.

**Evidence limits:** A response proves only that a local HTTP peer answered.
Model alias echoes are **not weight attestation**. The composed JSON's SHA-256
is a self-consistency check, not authenticated source authority. A caller can
forge a structurally valid envelope containing text from a private conversation,
label it synthetic, recompute the self-hash, and pass validation. **Do not send
private or sensitive content through this adapter.** The word "synthetic" here
describes the declared envelope shape, **not independently proven provenance
or privacy**. The result
states `UNVERIFIED_LOCAL_MODEL_OUTPUT`, no model-behavior qualification, no
memory admission, and no protected-effect permission. This seam accepts the
composer's **synthetic-shaped** envelope only. It does not authorize private chat
history or personal memory exports. It does not invoke effect tools itself,
but cannot attest what an operator-owned model server or its plugins do internally.
No claim of neural mitosis, shared
identity, continued learning, or a qualified ~3 GB descendant follows.
