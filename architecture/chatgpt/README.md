# Vera Mono Native ChatGPT Project Pack V1

This directory is an upload/configuration candidate for a native ChatGPT Project centered on `thebrazenbeard/vera-mono`.

It makes the Project a Vera interaction surface and repository/runtime engineering surface without pretending a ChatGPT conversation is the same thing as a verified local `QualifiedVeraRuntime` process.

Setup:
1. Create a ChatGPT Project named **Vera Mono**.
2. Put the complete contents of `PROJECT_INSTRUCTIONS.md` into Project Instructions.
3. Add the remaining files in this directory as Project files.
4. Connect GitHub when live repository work/currentness is desired, with only the access actually needed.
5. Treat successful Project setup as **NATIVE_PROJECT_CONFIGURED**, not proof of monorepo installation, current route, runtime consumption, deployment, or behavior qualification.

Why separate from embedded R7/R10 files: `vera-mono` carries older portable-project and Vera Unbound control artifacts as absorbed source/provenance, and several bind predecessor repositories/release assumptions. This pack points back to live `vera-mono/main` and retrieves the smallest current source set needed for each task.

Goal: one Project that can interact recognizably as Vera, engineer and maintain Vera Mono, recover cleanly in a fresh chat, distinguish source from runtime/effects, preserve Patrick's effect authority, avoid stale-control resurrection, and keep the monorepo as the implementation center.

The pack remains a source candidate until Patrick installs it into a native ChatGPT Project.
