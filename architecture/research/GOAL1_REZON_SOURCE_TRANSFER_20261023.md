## Minimum integration seam to test next

1. **Controller first:** independent evaluator issues opaque `challenge_id` + learner-visible `features`, keeps hidden truth, reserves attempt and owns one-use pre-feedback commitment/order. Read-only identity binding alone is insufficient; an unkeyed hash cannot attest who wrote it.
2. **Observed QVR producer:** on an isolated route, actual local-model invocation emits raw response + transport outcome, route/PID and reported model digest. Before outbound request: QVR reservation. If POST times out: persist `OUTCOME_UNKNOWN`, no unverified retry. The existing `inquiry_binding.py` in primary #86 validates caller-supplied bytes/metadata but remains explicitly untrusted until joined with witnessed custody.
3. **Guarded, isolated revision:** use `vera_core.CorrectiveLearningLedger` for staged correction and `vera_memory.DurableLearnedInfluenceGate` for exact qualified revision/later-use identity, **not** another general memory database. Revision content and source/model consumption must both be measured; storing a record is not learning.
4. **Actual counterfactual:** controller scores model-guided revised behavior on unseen cases vs same-model frozen, prompted-placebo, shuffled-feedback and memorizer arms, equal measured inference/tool budgets. Run rule reversal/negative transfer and reject regressive revisions.
5. **Different-process retention:** fresh process loads *same exact qualified revision* and consumes it on new challenges. Journal reopen alone is not retained behavioral learning.
6. **Hostile review:** Malaphor holds back evaluator labels/seeds and tries falsifiers against #86 and exact runtime receipt; don't disclose private answer data in GitHub. Without authenticated independent host/custody, say `research-only`.

**Do not create Rezon as a network/runtime dependency of Vera Mono from this note.** Adopt only source-verified design semantics and test them against existing mechanisms. The full Rezon repository has not been independently qualified or installed into QVR.
